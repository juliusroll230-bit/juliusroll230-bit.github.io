# Julius Thumbnails

Website für mein Thumbnail-Angebot: https://juliusroll230-bit.github.io

Die Seite steckt in `index.html` (Bilder eingebettet). Schriften und die 3D-Bibliothek three.js liegen im Ordner `assets/`, damit nichts von fremden Servern geladen wird.
Preise, E-Mail und Impressum stehen oben in der Datei im Block `EINSTELLUNGEN`.
