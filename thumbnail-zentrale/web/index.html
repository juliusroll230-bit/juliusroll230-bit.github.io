Einstellungen

Alles bleibt auf deinem Server. Automatisch wird nie etwas gesendet, nur wenn du selbst auf „Jetzt senden“ klickst.

Gmail verbinden

So bekommst du es: myaccount.google.com/apppasswords öffnen (dafür muss die Bestätigung in zwei Schritten an sein), Name „Thumbnail-Zentrale“ eingeben, das angezeigte Passwort hier einfügen.

Bankverbindung & Rechnung

Die IBAN steht nur auf Rechnungen und in Mails an Kunden, nie auf der Website.

Mail-Vorlagen

Platzhalter: {vorname}, {name}, {kanal}, {thema_satz}, {dein_name}, {monat}. {zahlung} wird zu Betrag, Frist, IBAN und Rechnungsnummer.

Preise

Änderst du die Preise im Website-Editor, werden sie hier automatisch übernommen.

Website-Editor

Auf github.com/settings/personal-access-tokens/new: Name „Thumbnail-Zentrale“, bei „Repository access“ nur dein Website-Repo wählen, unter „Permissions“ bei „Contents“ Read and write einstellen, erstellen und hier einfügen.

Änderungen in eigenen Worten (optional)
